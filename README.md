# Industrial Cleaning Services

Marketing site, booking system, and admin CRM for Industrial Cleaning
Services LLC.

**Start here:** [`HANDOFF.md`](./HANDOFF.md) — full setup, architecture, and
environment variable reference.

Quick start:

```bash
npm install
cp .env.local.example .env.local   # then fill in credentials
npm run dev
```

The schema for a fresh Supabase project is in
[`supabase-schema.sql`](./supabase-schema.sql).
